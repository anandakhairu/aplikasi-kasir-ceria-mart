# 🛒 Aplikasi Kasir Ceria Mart

Aplikasi point-of-sale (POS) untuk minimarket dengan tampilan 
yang mudah digunakan dan fitur lengkap.

## ✨ Fitur
- Dashboard kasir
- Menu produk berdasarkan kategori (Makanan, Minuman, Kebersihan, Rumah Tangga)
- Input pesanan & manajemen keranjang
- Proses pembayaran & cetak nota otomatis

## 🛠️ Teknologi
- Python
- Tkinter
- SQLite
